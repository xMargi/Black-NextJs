# Black Next 🛍️

Loja virtual desenvolvida com Next.js que exibe produtos, permite adicionar itens ao carrinho e acompanhar o total da compra.

![BlackNst](https://github.com/user-attachments/assets/8f292734-8b76-47a1-863d-b148b7491430)

## 🚀 Tecnologias

- Next.js 14
- TypeScript
- React
- Bootstrap / Reactstrap

## ✨ Funcionalidades

- Listagem de produtos
- Página de detalhes do produto
- Carrinho de compras
- Cálculo do total do carrinho
- Renderização estática e dinâmica de páginas

## ⚙️ Como rodar
```bash
npm install
npm run dev
```

Configure o `.env`:
```env
NEXT_PUBLIC_APIURL=http://localhost:3000
```

## 📁 Observação

O projeto consome uma API REST externa para buscar os produtos. Certifique-se de que a API esteja rodando antes de iniciar o frontend.
